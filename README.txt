Momen AI 2.0 - Cloudflare Pages upload

1. In Cloudflare Pages Drag and drop, set project name: momen-ai-2-web
2. Upload this ZIP file, or extract it and upload the folder contents.
3. The folder must contain index.html at its top level.
4. Deploy the project.
5. Open the generated pages.dev URL and test by sending: السلام عليكم

The page is configured to call:
https://moumenai2.moumentsaad.workers.dev/

If the AI replies with a Workers AI error, check the Worker binding name and model availability.
